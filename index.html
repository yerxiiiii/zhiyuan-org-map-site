智元组织架构

当前最稳的判断是，智元已经不是单线研发团队，而是“共享中台 + 产品线 + 嵌入式交付”的矩阵组织。

高置信结构推断 主要收入形态偏 ToB 更新于 2026-08-14

阅读顺序：最上层定方向，中间中台定标准，嵌入式角色把标准压到现场，最底层是实际承接收入和交付的业务线。

核心结论：多产品线 + 共享中台

方向、资源与关键节奏
C

CEO / 总裁层

统一牵引产品战略、商业化节奏、交付标准与跨产品线资源分配。

Shared Centers
统一方法、品牌、质量、服务与体验能力
市

品牌与市场传播

品牌体系、产品营销、海外社媒、事件传播。

负责声量、线索与品类教育
商

商业化中心

GTM、销售运营、伙伴体系、合同回款与国际物流。

负责“怎么卖”和“怎么结算”
产

产品与体验中心

平台产品、工业设计、UX、HCI、中央研究。

负责定义、交互和前瞻体验
服

营销服务体系

交付、售后、培训、客服、FAE、备件和服务商网络。

负责从交付到运维的全链路
质

质量体系

运营质量、研发质量、测试平台、SQE、供应商质量。

负责工业化语言和量产门槛
Embedded Roles
把中台标准压到产品线和客户现场
品

产品线质量总监

贴近 A2、人形和量产项目，直接负责批量交付质量。

后

产品线售后代表

把交付、返修、服务标准和一线问题闭环接起来。

交

交付 PM / 客户项目组

面向大客户、海外项目和群控项目做穿透式交付。

现

客服 / FAE / 海外支持

承担问题数据库、培训、远程排障和现场支援。

Business Units
当前最可能存在的产品线与业务树
人

人形机器人主线

灵犀 X1、灵犀 X2、G1、G2、精灵 G2、Genie。

A

通用产品线 / 远征 A2

标准化量产平台，承接 GTM、大客户验收与群控展示。

灵

灵心平台 / AgentOS

零代码 Agent 配置、知识库、记忆与调试体验。

手

灵巧手 / 关节模组

部件平台化能力，覆盖设计、测试和现场支持。

清

商业清洁

在设计和质量岗位里反复出现，像正式相邻业务线。

拓

四足 / 外骨骼研究线

当前更像相邻拓展线，成熟度低于人形和 A2。
