# 智元组织结构图与业务线图谱

这是一个可直接分享的单页 HTML 页面，用于展示基于简历线索逆向整理的智元组织结构图、业务线图谱和组织运行方式。

## 内容说明

- 页面文件：`index.html`
- 内容来源：基于本地整理的 `简历汇总.md` 与进一步分析稿的非官方推断
- 用途场景：团队内部讨论、竞对拆解、招聘判断、行业研究分享

## 使用方式

直接在浏览器中打开 `index.html` 即可。

如果发布到 GitHub Pages，默认把 `index.html` 放在仓库根目录即可直接作为首页使用。

## 风险说明

本页不是智元官方披露文件，而是根据公开招聘和候选人简历线索做出的逆向判断。对外引用时，建议明确标注“非官方推断”。
