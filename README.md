# 智元图谱

这是一个可直接分享的静态 HTML 图谱站点，用于展示基于简历线索逆向整理的智元组织判断。

## 页面结构

- `index.html`：组织架构
- `talent-distribution.html`：人才分布
- `talent-sources.html`：人才来源与招聘逻辑
- `assets/site.css`：三页共用样式

## 内容说明

- 内容来源：基于本地整理的 `简历汇总.md` 与进一步分析稿的非官方推断
- 使用场景：团队讨论、竞对拆解、招聘判断、行业研究分享
- 表达方式：偏架构图，而不是报告长页

## 使用方式

直接在浏览器中打开 `index.html` 即可，也可以部署到 GitHub Pages。

## 风险说明

本图谱不是智元官方披露文件，而是根据公开招聘与候选人简历线索做出的逆向判断。对外引用时，建议明确标注“非官方推断”。
